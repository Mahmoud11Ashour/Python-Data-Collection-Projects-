# IMDb Movie Data Preparation

- **Input:** `IMDB-Movie-Data.csv` (1,000 movie records, 12 columns).
- **Example processed output:** `processed_IMDB_Movie_Data.csv` (1,000 records, 32 columns).
- **Code:** `dataset1.py` and `DataSet1.ipynb`.
- **Methods:** Pandas-based exploration, cleaning, encoding/feature preparation, and plotting.

Run from this folder after installing the packages in the root `requirements.txt` file. The script may generate an `IMDB_Movie_Data_Cleaned.csv` output with a different filename from the supplied processed example.
