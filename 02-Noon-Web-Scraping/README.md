# Noon Product Web Scraping

- **Data source:** Product listing pages on Noon Saudi Arabia.
- **Code:** `dataset2.py` and `DataSet2.ipynb`.
- **Tools:** Requests, BeautifulSoup, Pandas, NumPy.
- **Dataset:** `products_data_from_noon.csv` (1,000 raw rows) and `processed_products_data_from_noon.csv` (989 processed rows).
- **Fields:** Product name, price, ratings, review counts, discount and release date, with additional derived features in the processed sample.

The scraping code depends on Noon HTML and should only be run in accordance with applicable site rules. It has not been live-tested for the website's current layout.
